# راهنمای فعال‌کردن README اختصاصی GitHub

## چرا صفحهٔ پروفایل هنوز سربرگ را نشان نمی‌دهد؟

GitHub فقط در صورتی فایل README یک ریپو را **بالای صفحهٔ پروفایل** نمایش می‌دهد که ریپوی عمومی با **نام دقیق حساب کاربری** ساخته شده باشد. نام حساب این پروژه: **iAlirezaaa**.

مخزن فعلی هنگام تهیهٔ این راهنما: https://github.com/iAlirezaaa/Hades-3rd

## تغییر نام (یک‌بار)

1. به [Settings مخزن فعلی](https://github.com/iAlirezaaa/Hades-3rd/settings) برو.
2. در **General → Repository name**، نام را از **Hades-3rd** به **iAlirezaaa** تغییر بده.
3. **Rename** را انتخاب کن.
4. به **https://github.com/iAlirezaaa** برو. سربرگ README بالای پروفایل می‌آید؛ در صورت نیاز صفحه را Refresh کن.

**تفاوت نام‌ها:** نام مخزن باید iAlirezaaa باشد، ولی متن و هویت بصری هدر همچنان HADES THE THIRD است. برای همین فقط نام ریپو را تغییر می‌دهیم، نه نام حساب یا برند.

اگر ریپوی هم‌نام iAlirezaaa از قبل ساخته شده باشد، ابتدا باید موضوع تداخل نام برطرف شود. ریپوی پروفایل باید Public باشد و README.md در ریشهٔ شاخهٔ پیش‌فرض باقی بماند.
